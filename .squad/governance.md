# Governance

- **Ownership:** One accountable specialist per work item, chosen via `.squad/routing.md`.
- **Review gate:** Tester reviews combined gameplay and visuals work. Routine work has at most one blocking gate.
- **Rejection:** On rejection the original author is locked out of that revision; a different member revises.
- **Constraints:** No runtime dependencies, no build step, no external network assets.
- **Scope:** Specialists deliver only the requested scope. Adjacent ideas are reported, not implemented.
- **Repository requirements:** See `.github/PR_REQUIREMENTS.md` when present.
